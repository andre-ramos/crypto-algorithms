# crypto-algorithms

This repository is a study collection of cryptography algorithms and related exercises implemented in Python.

## What it includes

- Classical ciphers such as Caesar, substitution, permutation, and one-time pad
- DES-related experiments, including double DES examples
- Public key topics such as RSA and Diffie-Hellman
- Hashing, HMAC, stream cipher, and frequency analysis exercises

## Why I built it

I used this project to practice the fundamentals behind cryptography by implementing the algorithms directly instead of only reading about them.

## Project structure

Each script focuses on one concept or algorithm, so the repository works more like a notebook of experiments than a single packaged application.

## Tech

- Python

## Notes

This repo is educational in nature and should be treated as a learning project rather than production cryptography code.
